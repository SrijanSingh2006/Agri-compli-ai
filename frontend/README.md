## Run Locally

1. Start backend API from project root:
   `python app.py`
2. In this folder, install dependencies:
   `npm install`
3. Start frontend:
   `npm run dev`

The AI assistant uses `VITE_API_BASE_URL` (default: `http://127.0.0.1:5001`).
